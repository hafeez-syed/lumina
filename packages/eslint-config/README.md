# `@lumina/eslint-config`

Collection of internal eslint configurations shared across the LUMINA monorepo.

Exports three configs:

| Import                              | Use for                          |
| ----------------------------------- | -------------------------------- |
| `@lumina/eslint-config/base`         | any package                      |
| `@lumina/eslint-config/next-js`      | the Next.js app (`apps/web`)     |
| `@lumina/eslint-config/react-internal` | internal React libraries (`packages/ui`) |
